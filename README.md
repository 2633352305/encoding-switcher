# 编码自动切换器 (encoding-switcher)

打开文件时**自动检测编码格式并以正确编码打开**，同时支持 **GB2312 ⇄ UTF-8** 一键转换，防止中文注释乱码；按源编码解码保存，内容不损坏。

作者：**上了个大笔当**

## 功能

- **自动检测并正确打开**（主要功能）：打开文件时自动检测 GB2312/GBK/UTF-8 编码，并以正确编码显示，无需任何操作，中文注释不乱码
- **一键切换编码保存**（辅助功能）：编辑器标题栏按钮——GB2312/GBK 文件显示「以UTF-8编码保存」，UTF-8 文件显示「以GB2312编码保存」；也可在命令面板执行
