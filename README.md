# 编码自动切换器 (encoding-switcher)

打开文件时**自动检测编码格式并以正确编码打开**，同时支持 **GB2312 ⇄ UTF-8** 一键转换，防止中文注释乱码；按源编码解码保存，内容不损坏。

作者：**上了个大笔当**

## 功能

- **自动检测并正确打开**（主要功能）：打开文件时自动检测 GB2312/GBK/UTF-8 编码并以正确编码显示，中文注释不乱码。
- **标题栏双按键**（只在打开 .c/.h 文件时显示）：
  - **左键 = 选范围**：单文件图标 = 只转当前文件（默认）⇄ 文件夹图标 = 转所在文件夹全部 .c/.h。点击来回切换，仅本次会话有效，批量开始后自动复位
  - **右键 = 执行**：GB2312/GBK 文件显示「以UTF-8编码保存」，UTF-8 文件显示「以GB2312编码保存」；按左键选定的范围执行；也可在命令面板执行
- **批量转换**（弹窗确认后才执行）：仅处理目标文件夹顶层的 .c/.h（不含子文件夹）；安全规则——已损坏（解码含乱码替换符）跳过、转换会丢字符（round-trip 有损）跳过、有未保存修改跳过
- **设置项**（兼容入口）：`encoding-switcher.batch.target` 目标编码、`exclude` 排除文件名

## 两个按键怎么用

**第 1 个按键：选范围**（点击在两种范围之间来回切换）

| 当前显示 | 含义 |
|---------|------|
| 📄 单个文件图标 | 只转换**当前打开的这一个文件**（默认状态） |
| 📁 文件夹图标 | 批量转换**当前文件所在文件夹**顶层的全部 .c/.h（不含子文件夹） |

**第 2 个按键：执行**（文字按钮，随文件当前编码变化）

| 文件当前编码 | 按钮显示 | 点击效果 |
|-------------|---------|---------|
| GB2312/GBK | 以UTF-8编码保存 | 转为 UTF-8 |
| UTF-8 | 以GB2312编码保存 | 转为 GB2312 |

**例子**：用左键选「📁 文件夹」→ 右键点「以GB2312编码保存」→ 弹窗确认后，当前文件所在文件夹里的所有 .c/.h 全部转为 GB2312。

## 限制

- 文件本身已损坏的乱码（如历史上被错误转码固化的「锟斤拷」类内容）无法通过切换编码恢复，只能人工修复
- 转换与自动纠偏的重开均按实际编码锁定内核解码，不依赖内核猜测；极端情况下（旧模型未及时释放）可能仍刷新失败，为避免焦点风暴只重试 1 轮，关闭文件标签重新打开即可恢复
- `files.candidateGuessEncodings` 设置需 VS Code ≥1.85，旧版本会忽略（不影响基本功能）
